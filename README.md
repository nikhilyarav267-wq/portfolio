# EDIT WITH NIK. — Portfolio

Mobile-first video editor portfolio with vertical 9:16 video cards.

## Contact links

Open `index.html` and replace:
- `https://instagram.com/yourusername`
- `@yourusername`
- `https://wa.me/91XXXXXXXXXX`
- `+91 XXXXX XXXXX`

The Instagram card opens the Instagram profile. The WhatsApp card opens a direct WhatsApp chat.

## Videos

Put your MP4 files in `videos/` and use these filenames in `index.html`:
- hero.mp4
- real-estate-01.mp4
- talking-head-01.mp4
- motion-graphics-01.mp4

More project videos can be added later.

## Publish

Upload the folder to a public GitHub repository and enable GitHub Pages under Settings → Pages.
